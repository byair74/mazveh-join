# דף ההזמנה של מזווה

דף סטטי אחד (`index.html`) שנפתח מהקישור של הזמנה למזווה. הוא קורא את הקוד מהכתובת (החלק אחרי `#`, שהדפדפן לא שולח לשום שרת), מסביר מה קיבלו, ופותח את האפליקציה בקישור `mazveh://join?code=...`. אם האפליקציה לא נפתחת, אפשר להעתיק משם את הקוד ולהדביק אותו במזווה.

## פרטיות

- הריפו ציבורי **בכוונה**: GitHub Pages בחשבון חינמי עובד רק עם ריפו ציבורי.
- אין בו שום נתונים, טוקנים או הגדרות. הדף לא שומר ולא סופר כלום, והקוד נשאר בדפדפן.
- אל תעלו לכאן שום דבר מלבד הדף הזה.

## הפעלה

Settings > Pages > Source: **Deploy from a branch**, ענף `main`, תיקייה `/ (root)`, Save. אחרי כדקה הדף עובד בכתובת
`https://<שם המשתמש>.github.io/mazveh-join/`.

האפליקציה מחפשת את הדף בכתובת הזאת. אם הריפו או החשבון שונים, מקלידים את הכתובת באפליקציה: עוד > סנכרון בין מכשירים > הגדרות מתקדמות > "כתובת דף ההזמנה". כל עוד הדף לא עונה, האפליקציה שולחת בהזמנה את הקוד עצמו, בלי קישור.

## קישור להורדת האפליקציה

אם יש קישור ציבורי להורדת קובץ ההתקנה (APK), מקלידים אותו במשתנה `APK_URL` בראש הסקריפט של `index.html`, ובדף יופיע כפתור "הורדת האפליקציה". כשהוא ריק, הכפתור מוסתר.
